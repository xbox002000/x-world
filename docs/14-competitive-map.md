## Category wedge

Most adjacent tools optimize **metrics, scheduling, hygiene, or drafting**. Few make **navigable graph world → Next Best Action** the core loop.

**Wedge:** Interactive X Growth World whose primary output is a user-gated NBA (not another analytics dashboard, not volume automation).


## 1) Fedica (formerly Tweepsmap)

| Lens | Notes |
|------|-------|
| What | Audience intelligence + multi-platform publishing/analytics |
| Whom | Social managers, X power users, brands |
| Core loop | Analyze audience → schedule/publish → review growth |
| Data source | Platform integrations / official API (vendor-claimed) |
| Return reason | Demographics, maps, follower insights |
| Monetization | Freemium; Grow ~$19–29/mo (2026 roundups) |
| Weakness | Dashboard-heavy; not NBA-world; broad multi-network dilutes X-native graph play |

Sources: Fedica review / Circleboom alternative posts (SocialRails, who.unfollowed.me blog, 2026).
